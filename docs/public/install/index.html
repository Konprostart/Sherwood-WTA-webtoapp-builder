Questions

      

        Is it free?
        
Yes. Sherwood Studio is public-domain open source; the full source is on GitHub.

      

      

        Which file should I download?
        
The standard APK — unless you specifically want the Play-ready build, which is the second button.

      

      

        Do I lose my apps when I update?
        
No. Every release since 2.9.0 is signed with the same key, so updates install over the previous version and keep your data.
